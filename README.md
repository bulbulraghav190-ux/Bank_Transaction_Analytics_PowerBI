# Bank Transaction Analytics Dashboard

A simple **Power BI dashboard** created to analyze bank transaction data and understand transaction trends, amounts, and remaining balances.

## 📊 Dashboard Features

* Monthly transaction analysis for **2024**
* Transaction amount and remaining balance analysis
* City-wise analysis
* Payment mode and transaction type analysis
* Filters for gender, age group, device type, merchant, and purpose
* Currency-wise analysis

## 🛠️ Tools Used

* **Power BI**
* **Data Visualization**
* **Data Analysis**

## 📁 Files Included

* `Bank Dashboard.pdf` — Dashboard preview

## 🎯 Project Goal

The main goal of this project is to turn transaction data into simple and useful visual insights using Power BI.
